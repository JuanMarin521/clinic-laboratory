03 · ARCHITECTURE

One logical architecture, two runtimes.

Expo clientscreens · navigation · auth state
Express API/api/v1
Application servicesauth · orders · exams · profile · support · PDF
SQLitefile-backed data

Controllers translate HTTP; services hold rules; repositories are the SQL boundary. Optional Gemini is an external conditional path.

04 · BACKEND

The backend makes ownership explicit.

Identity

JWT + bcrypt

Protected routes resolve the patient from the token. Passwords are hashed and public responses omit the hash.

Domain

Orders → exams

Queries are scoped to the authenticated user. Summaries are derived from ready, processing, and issue states.

Documents

PDF in memory

Only validated exams are included. The client saves or shares the returned binary bytes.
